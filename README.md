# ApexStudio Digital Agency

> Award-winning Swiss editorial digital design & AI engineering

Built autonomously from voice requirements using **[VoxBuild AI](https://voxbuild.ai)**.

## Architecture
- **Framework**: Next.js 15 (App Router) & React 19
- **Archetype**: AGENCY
- **Styling**: Tailwind CSS (Swiss Editorial Bento Grid with Warm Amber Accents)
- **Backend**: Ready for Supabase PostgreSQL
- **Deployed on**: Vercel Global Edge Network

## Getting Started
```bash
npm install
npm run dev
```
